# 📋 Fundamentos de Requisitos de Software

Repositório de estudos sobre **requisitos funcionais e não funcionais**, com conceitos, exemplos práticos e exercícios de Engenharia de Software.

O objetivo é aprender a identificar, descrever e organizar os requisitos de um sistema antes de sua implementação.

## 🎯 Objetivos

- Entender a diferença entre requisitos funcionais e não funcionais.
- Aprender a escrever requisitos claros e verificáveis.
- Aplicar os conceitos em um exemplo de sistema.
- Revisar o conteúdo com exercícios.

## 🧠 Resumo rápido

- **Requisito funcional (RF):** descreve uma funcionalidade ou comportamento que o sistema deve oferecer.
- **Requisito não funcional (RNF):** descreve uma qualidade, condição ou restrição do sistema, como desempenho, segurança ou compatibilidade.

## 🗂️ Exemplo

Em um sistema de delivery:

- **RF01:** O sistema deve permitir que o cliente adicione produtos ao carrinho.
- **RNF01:** Nas condições de teste definidas, a página inicial deve carregar em até 2 segundos.

> Observação: os valores usados nos exemplos são ilustrativos. Em um projeto real, os requisitos devem ser discutidos e validados com as pessoas envolvidas.
